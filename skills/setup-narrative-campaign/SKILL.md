# Setup Narrative Campaign

Read [the workflow contract](references/workflow.md) before acting.

Use only currently exposed SagaSmith Narrative MCP tools. Discover capabilities first, collect explicit human choices, create the campaign in Lobby, bind an exact finalized profile and Pack versions, establish roles and actor grants, validate authoritative readiness, then enter Play only when the caller asks.

Treat preferences and presentation gaps as warnings. Block only for missing permission, unresolved participant choice, stale authority, incompatible dependencies, or mechanically indispensable data.

After any campaign, profile, phase, role, actor-grant, branch, or restore change, discard stale tool schemas and context, refresh exposure, and re-read authoritative state.
