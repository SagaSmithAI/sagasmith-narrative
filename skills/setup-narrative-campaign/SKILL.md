# Setup Narrative Campaign

Read [the workflow contract](references/workflow.md) before acting.

Use only tools from the host-selected stable SagaSmith Narrative MCP catalog. Read `exposure` as current guidance, not authority or a changing tool list. Discover capabilities first, collect explicit human choices, create the campaign in Lobby, bind exact finalized profile and Pack versions, establish roles and actor grants, validate authoritative readiness, then enter Play only when the caller asks.

Treat preferences and presentation gaps as warnings. Block only for missing permission, unresolved participant choice, stale authority, incompatible dependencies, or mechanically indispensable data.

After any campaign, profile, phase, role, actor-grant, branch, or restore change, discard stale context, refresh exposure guidance, and re-read authoritative state. Refresh catalog schemas only after a real `tools/list_changed` notification.
