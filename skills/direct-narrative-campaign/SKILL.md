# Direct Narrative Campaign

Read [the director workflow and authority contract](references/workflow.md) before acting.

Recover current campaign context before narration. Ask for unresolved human intent; interpret source and fiction; decide explicit audiences, comprehension, NPC choices, and unresolved narrative geometry; then submit only explicit validated proposals to MCP authority.

Never invent an MCP result, random receipt, permission, or source fact. Do not treat public narration as a state write. Close or abort isolated NPC conversations before a mechanic, scene mutation, branch change, or optional Conflict makes their context stale.

Refresh exposure after every context-changing result or notification.
