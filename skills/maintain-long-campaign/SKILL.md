# Maintain Long Campaign

Read [the long-term maintenance contract](references/workflow.md) before acting.

Start from branch-scoped authoritative state and the active profile. Ask the Agent or authorized humans to choose semantic world developments; use MCP rules and random streams only where explicitly declared; submit explicit, source-backed deltas in one world-turn or downtime settlement.

Do not make summaries authoritative, run hidden automatic world simulation, or advance every clock merely because time passed. Treat readiness and presentation diagnostics as warnings unless a concrete invariant is at risk.

Refresh context after every settlement, time jump, phase, profile, branch, or restore change.
