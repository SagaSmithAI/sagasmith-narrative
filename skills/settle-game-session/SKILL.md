# Settle Game Session

Read [the session-close contract](references/workflow.md) before acting.

Inventory all unsettled proposals and active isolated conversations. Resolve or explicitly defer each item, close stale activities, commit one authoritative session settlement, verify revisions and receipts, create an optional snapshot, then derive audience-specific summaries from committed state.

Never let a prose recap become the source of truth. Do not close over unresolved player choices, missing permission, mechanically indispensable missing data, or stale revisions. Optional artwork and presentation fields never block closure.

After settlement or snapshot creation, refresh context before starting more play.
