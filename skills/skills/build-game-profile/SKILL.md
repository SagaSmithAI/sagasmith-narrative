# Build Game Profile

Read [the profile workflow and trust boundary](references/workflow.md) before acting.

Work only on MCP-owned profile drafts. Record source evidence and explicit semantic decisions, use the bounded declarative mechanics surface, validate repeatedly, and finalize only after an authorized reviewer confirms the draft. Never infer executable rules from prose or silently widen the profile language.

Escalate to an independent system package when mechanics require multi-step reaction windows, complex derived state, unique authoritative phases, or cross-entity invariants that the declared profile operations cannot express.

Refresh exposure and authoritative campaign context after profile activation, migration, or capability changes.
